# Jellyflow roadmap

Jellyflow is an early beta. The immediate goal is dependable everyday playback before expanding into the full Jellyfin feature set.

## Now — playback confidence

- Use Jellyfin playback negotiation and device profiles instead of assuming a single HLS path.
- Add automatic next-episode playback and a visible playback queue.
- Add browser and mobile playback regression coverage.
- Capture privacy-safe screenshots for the project page.

## Next — library control

- Add favourites and manual watched/unwatched controls throughout the library.
- Improve music with album, artist, track and persistent queue views.
- Round out subtitles, audio-track selection and playback quality controls.

## Later — shared and advanced use

- Downloads and offline-friendly behaviour.
- Casting and SyncPlay.
- More complete administrative and user settings.

Priorities may change based on real-world testing and community feedback. Please use GitHub Issues for concrete work and GitHub Discussions for broader product ideas.
